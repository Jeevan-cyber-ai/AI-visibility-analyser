Frequently Asked Questions

Does PulseTask support automated GitHub pull request linking?

Yes. PulseTask automatically associates GitHub and GitLab pull requests with sprint backlog items based on branch naming conventions (e.g., feat/PT-142-auth). When a PR is approved or merged, the corresponding PulseTask ticket transitions automatically without manual intervention.

Is PulseTask SOC2 Type II certified for enterprise security?

Yes. PulseTask maintains active SOC2 Type II, ISO 27001, and GDPR compliance certifications with 256-bit AES encryption at rest and TLS 1.3 encryption in transit.
